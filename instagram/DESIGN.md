# FYND 인스타 디자인 공통 규칙

기존 게시물(FYND 이야기 1~4부, 가게 소개 GREENY BOX·영진관광)에서 뽑은 규칙이다. 시리즈마다 디자인은 달라도 되지만, 아래 공통 장치는 모든 게시물에 들어간다. 그래서 피드에서 "같은 계정이 만들었다"는 느낌이 난다.

새 게시물은 `instagram/tools/fynd-cards.css`를 불러 쓰고, 게시물만의 배치만 각 `slides.html`에 덧붙인다.

## 1. 모든 카드에 들어가는 것

| 장치 | 모양 | 비고 |
|---|---|---|
| 여백 | 사방 84px, 4:5 (1080×1350) | |
| 위 눈썹 라벨 | 빨간 점(12px) + 회색 고정폭 글자 22px, 가운데 | 예: `● 03 · 인건비` (가게 시리즈는 빨간 태그 글자) |
| 아래 바 | 가는 선 위에 `FYND`(굵게) + 쪽번호 `03 / 10`(고정폭, 흐리게) | 사장님 대상 시리즈는 가운데, 가게 시리즈는 FYND 왼쪽·쪽번호 오른쪽 |
| 레드 | #DD010F 하나 | 점, 알약 배지, 강조 띠, CTA에만 |
| 고정폭 숫자 | DejaVu Sans Mono | 쪽번호, 순서 번호, 날짜, 전화·이메일 |

## 2. 강조는 세 가지만

1. **빨간 띠** (`.hl`): 핵심 문구 뒤에 빨간 배경, 모서리 5px. 한 장에 하나
2. **빨간 알약 배지** (`.badge`): 장의 주제나 조건 ("문의부터 약 1주", "할 일")
3. **빨간 점**: 목록 머리, 눈썹 라벨

쓰지 않는 것: 왼쪽 색 막대가 붙은 상자, 커다란 빨간 숫자, 아이콘을 원 안에 넣은 장식, 이모지, 그림자 많은 카드, 버건디 말고 다른 그라데이션.

## 3. 시리즈별 바탕

**사장님에게 말하는 시리즈** (FYND 이야기, 사장님 노트, 사장님 알림판)
- 다크 #0A0A0B 기본. 장마다 바탕을 돌린다: 기본 / 격자(72px) / 버건디(아래에서 올라오는 붉은 기운) / 흰 카드 #F7F7F8
- 짧은 문장은 가운데 정렬 스탠자(47px, 굵게) + 흐린 보조 문장(32px, #B8B8BC)
- 정보가 많은 장은 왼쪽 정렬 정보표(가게 소개 '한눈에 보기'와 같은 줄 구성)
- 순서 목록은 고정폭 숫자 `01 02 03`을 30% 투명도로

**가게 시리즈** (가게 소개, 가게 이야기)
- 종이 회색 #F0F0F1 + 잉크 #121214, 사진은 위쪽 760~800px
- 제목은 명조(Noto Serif KR Bold), 본문은 고딕
- 마지막 장은 잉크 #121214 바탕 + 정보표 + 빨간 둥근 CTA

## 4. 고정 클로징 (사장님 대상 시리즈)

왼쪽 위 큰 문장(70px) → 작은 설명(25px, 회색) → 아래 빨간 둥근 CTA 상자(모서리 18px) → 오른쪽 위 고정폭 `FYND`. 마지막 장에는 쪽번호 바를 넣지 않는다.

## 6. AI 티를 줄이는 습관

- 장마다 같은 장치를 반복하지 않는다. 빨간 띠는 한 장에 하나, 배지는 꼭 필요한 장에만
- 상자를 늘어놓지 않는다. 정보는 줄과 선으로 정리한다
- 문장은 담백하게. 헤드라인은 완결된 문장
- 사진 자리는 점선 상자 + 라벨로 비워 두고, 실제 사진은 Canva에서 채운다
