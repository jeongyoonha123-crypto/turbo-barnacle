# 릴스 01 — 버스 좌석 4,500석

- 목적: 팔로워 밖으로 퍼지는 훅 릴스. 첫 1초에 숫자(0 → 4,500)가 올라가며 멈추게 만들고, 끝에서 댓글 '버스'를 부른다
- 형식: 9:16 (1080×1920), 16.8초, 움직이는 글자(숫자 카운트, 밀어 올리기, 빨간 띠 지우기), 소리 없음 → 인스타 앱에서 음악
- 파일: `reel.mp4`(영상), `cover.png`(커버, 4,500석 장면), 원본 `reel.html`
- 다시 만들기: `FONT_CSS=<fonts.css> node instagram/tools/render-reel.cjs <reel.html> 16.8 <reel.mp4> 1.7`
- 사실 근거: 영진관광 45인승 버스 100대 이상 파트너십(`docs/01`) → 100 × 45 = 4,500석. 선착순 20곳 상단 고정(`docs/01`). 실제 계약 업체 사례·회비 금액은 넣지 않음(회비 문구는 아직 확정 전)

## 흐름

| 시간 | 화면 |
|---|---|
| 0~2.0초 | 충남을 달리는 버스 좌석 → **0에서 4,500석까지 숫자가 올라감** (로고) |
| 2.0~3.9초 | 영진관광 45인승 버스 **100대**가 넘어요. |
| 3.9~5.6초 | 좌석 뒤마다 QR이 붙습니다. (QR 그림이 튀어나옴) |
| 5.6~9.4초 | 손님이 QR을 찍으면 → 휴대폰 카메라 스캔선 → 'fynd-cnd.onrender.com' 알림 → 눌러서 **실제 FYND 페이지**가 열리고 아래로 내려감 |
| 9.4~11.4초 | 손님이 찍으면 뜨는 건 → **충남 동네 가게**(빨간 띠) 입니다. |
| 11.4~13.6초 | 맨 위 자리는 **20곳**, 먼저 오는 순서로. |
| 13.6~16.8초 | 우리 가게도 될까요? → 댓글에 '버스' 남겨 주세요 (로고, 네트워크 한 줄) |

- 휴대폰 화면: QR 연결 페이지(fynd-cnd.onrender.com)를 10/21에 휴대폰 크기로 캡처한 `site-mobile.jpg`. 인스타에 쓰면 안 되는 카드 3개(테스트 데이터 아이뽀란, 아이 사진이 있는 예산 애플 유나이티드, AI 연출 이미지가 있는 FLUFFY·D)는 가리고 찍음. 크로바양계·GREENY BOX·PAMP·충남의 행사·가게 소개 신청이 보임

## 캡션

```
충남 버스 좌석 4,500석, 그 QR에 어떤 가게가 뜰까요?

영진관광 45인승 버스 100대가 넘게 충남을 달려요.
좌석 뒤 QR을 손님이 찍으면, 충남 동네 가게가 나옵니다.

맨 위 자리는 먼저 오는 20곳.
우리 가게도 될지 궁금하면 댓글에 '버스'를 남겨 주세요. DM으로 알려 드려요.

FYND는 충남 사장님들이 서로 돕는 네트워크를 만듭니다.

#충남소상공인 #충남맛집 #홍성 #천안 #FYND
```
